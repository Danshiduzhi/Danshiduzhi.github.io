开始之前，你可能想问

只有照片或草图，可以建模吗？

可以先判断。照片适合做外形参考；精确结构还需要尺寸、多角度照片或草图。已有 STL、STEP 或 3MF 文件，也可以只咨询代打。

AI Agent 指导包含什么，费用怎么计算？

主要包含环境检查、依赖配置、API 与常用工具接入、启动指导和基础排错。按系统、工具和实际工作量先确认报价；模型订阅或 API 用量费用需另行确认，不包含在安装指导费中。不要发送密码或 API 密钥，授权与登录由你本人完成。

咨询时，需要准备什么？

说明用途、已有素材、期望结果、交付时间和预算。打印需求再补充尺寸、数量、材料与颜色；AI 工具需求补充电脑系统、工具名称和报错截图。涉及文化素材时，先说明背景与授权情况。
